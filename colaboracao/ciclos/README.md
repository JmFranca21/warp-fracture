# Registro dos ciclos automáticos

Um arquivo por ciclo (`AAAA-MM-DD_cNN.md`), escrito pelo gerente de projeto no fechamento. Cada um traz o que cada papel fez, o que o revisor aprovou ou devolveu, os commits e o que fica para o ciclo seguinte. As regras estão em [FLUXO_AUTOMATICO.md](../FLUXO_AUTOMATICO.md).
